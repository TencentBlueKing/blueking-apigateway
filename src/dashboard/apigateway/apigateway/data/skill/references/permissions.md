# 如何申请权限

每个 Skill 包里的本文件内容相同。要调用哪些接口、要不要申请，看 SKILL.md「接口清单」的「用户认证」「应用认证」「需申请权限」「OAuth2 public client」「OAuth2 personal client」列。

## 申请网关接口权限

「需申请权限」为「是」的资源：在蓝鲸开发者中心（{{ developer_center_url }}）打开应用，进入「云 API 权限」→「网关 API」，按网关搜索并勾选这些资源后提交申请，审批通过后生效。

「需申请权限」为「否」时，不必申请网关接口权限。

## OAuth2 内置应用

「OAuth2 public client」或「OAuth2 personal client」为「是」时，网关在发布时已经把该资源授权给对应的 OAuth2 内置应用（`public` 或 `personal`）。用这类客户端调用时不必再申请网关接口权限。这两项为「是」的资源同时要求用户认证。

## 业务权限

网关接口权限只决定应用能否调用接口。接口返回无业务权限（如 IAM 错误码 `9900403`）时，到对应业务系统申请业务、模板、方案或项目的操作权限，不要重复申请网关权限。
