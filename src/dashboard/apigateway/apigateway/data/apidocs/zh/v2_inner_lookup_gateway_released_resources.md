### 描述

按名称查询指定网关当前各**启用环境**（`stage.status = ACTIVE`）`Release` 引用的资源版本中的资源并集。接口不分页；未匹配的资源名称不会出现在结果中。

接口不按网关状态、网关公开状态、资源公开状态或资源 OAuth2 开关过滤，但仍遵守租户可见性约束。同一资源 ID 出现在多个当前版本时只返回一个快照；先按快照名称精确过滤，再按资源 ID 去重，默认选择版本 ID 较大的快照。

多租户模式下必须通过 `X-Bk-Tenant-Id` 请求头传入当前租户 ID，否则返回 `400`。跨租户访问统一返回 `404`。

### 输入参数

#### 路径参数

| 参数名称 | 参数类型 | 必选 | 描述 |
|---|---|---|---|
| gateway_name | string | 是 | 网关名称 |

#### 请求参数

| 参数名称 | 参数类型 | 必选 | 描述 |
|---|---|---|---|
| names | string | 是 | 资源名称列表，精确匹配，多个以逗号分隔，去重后最多 50 个 |
| fields | string | 否 | 返回字段列表，多个以逗号分隔；支持 `id`、`name`、`description`、`is_public`，不传返回全部字段 |

### 响应示例

```json
{
  "data": [
    {
      "id": 101,
      "name": "get_user",
      "description": "查询用户",
      "is_public": true
    }
  ]
}
```

### 响应参数说明

| 字段 | 类型 | 描述 |
|---|---|---|
| data | array | 匹配的当前已发布资源列表，无分页包装 |
| data[].id | int | 资源 ID |
| data[].name | string | 资源名称 |
| data[].description | string | 当前快照中的资源描述，随请求语言返回中文或英文 |
| data[].is_public | bool | 资源是否公开 |

网关不存在或对当前租户不可见时返回 `404`；网关不存在当前发布版本或名称均未匹配时返回空数组。
