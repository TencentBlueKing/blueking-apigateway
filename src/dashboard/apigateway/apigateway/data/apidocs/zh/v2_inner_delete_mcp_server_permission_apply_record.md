### 描述

删除已取消的 MCP Server 权限申请记录。仅 `canceled` 状态的记录可以删除。

### 输入参数

#### 路径参数

| 参数名称  | 参数类型 | 必选 | 描述        |
|-----------|----------|------|-------------|
| record_id | int      | 是   | 申请记录 ID |

#### 请求参数

| 参数名称        | 参数类型 | 必选 | 描述           |
|-----------------|----------|------|----------------|
| target_app_code | string   | 是   | 申请权限的应用 |
| operated_by     | string   | 是   | 操作人         |

### 响应

删除成功返回 HTTP 204。
