### 描述

按用户名批量删除网关维护人，供 PaaS 同步维护人删除。

不存在于当前网关成员列表中的用户将被忽略。删除后网关必须至少保留一个管理员。


### 输入参数

#### 路径参数

| 参数名称 | 参数类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| gateway_name | string | 是 | 网关名称 |

#### 请求体参数

| 参数名称 | 参数类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| maintainers | array | 是 | 待删除的网关维护人，至少一个用户名 |


### 请求示例

```json
{
    "maintainers": ["user-a", "user-b"]
}
```


### 响应示例

```json
{
    "data": {
        "deleted": ["user-a"]
    }
}
```


### 响应参数说明

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| data.deleted | array | 实际删除的网关维护人；不存在的用户不会出现在列表中 |


### 错误码

| 错误码 | 描述 |
| --- | --- |
| 400 | 参数校验失败，或删除后网关将没有管理员 |
| 404 | 网关不存在 |
