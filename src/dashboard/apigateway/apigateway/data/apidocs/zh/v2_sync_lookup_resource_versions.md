### 描述

按 ID 或版本号批量查询指定网关的资源版本。接口不分页，未匹配或属于其他网关的资源版本不会出现在结果中；同时传入 ID 和版本号时返回两组条件的交集。

### 输入参数

#### 路径参数

| 参数名称 | 参数类型 | 必选 | 描述 |
|---|---|---|---|
| gateway_name | string | 是 | 网关名 |

#### 请求参数

| 参数名称 | 参数类型 | 必选 | 描述 |
|---|---|---|---|
| ids | string | 否 | 资源版本 ID 列表，多个以逗号分隔，最多 50 个；与 `versions` 不能同时为空 |
| versions | string | 否 | 版本号列表，精确匹配，多个以逗号分隔，最多 50 个；与 `ids` 不能同时为空 |

### 响应示例

```json
{
  "data": [
    {
      "id": 1,
      "version": "1.0.0",
      "comment": "首次发布"
    }
  ]
}
```

### 响应参数说明

| 字段 | 类型 | 描述 |
|---|---|---|
| data | array | 匹配的资源版本列表，无分页包装 |
| data[].id | int | 资源版本 ID |
| data[].version | string | 版本号 |
| data[].comment | string | 版本说明 |
