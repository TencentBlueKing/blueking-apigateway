### 描述

取消待审批的 API 网关权限申请。仅 `pending` 状态的记录可以取消。

### 输入参数

#### 路径参数

| 参数名称  | 参数类型 | 必选 | 描述        |
|-----------|----------|------|-------------|
| record_id | int      | 是   | 申请记录 ID |

#### 请求参数

| 参数名称        | 参数类型 | 必选 | 描述           |
|-----------------|----------|------|----------------|
| target_app_code | string   | 是   | 申请权限的应用 |
| operated_by     | string   | 是   | 操作人         |

### 响应

取消成功返回 HTTP 204。
