# 功能: 资源配置 - 导入导出资源

**模块**: 资源配置
**页面**: /:id/resource/setting
**优先级**: P1
**前置条件**: 用户已登录，本次隔离网关已有default后端与资源

## 场景: 导入资源

- **当** 用户上传合法OpenAPI文件，预览后确认导入
- **那么** 导入响应成功，页面显示成功导入1个资源
- **并且** API回查验证名称、方法、路径以及自动生成的资源文档

## 场景: 无效OpenAPI文件阻止导入

- **当** 上传缺少必要字段的OpenAPI文件
- **那么** 页面显示具体校验错误，下一步禁用，不能确认导入

## 场景: 导出全部资源 - JSON

- **当** 用户导出全部资源并选择JSON格式
- **那么** 必须收到成功下载事件，文件可解析为OpenAPI，operationId集合与全部资源完全一致

## 场景: 导出全部资源 - YAML

- **当** 用户导出全部资源并选择YAML格式
- **那么** 必须收到成功下载事件，文件非空并包含全部资源名称

## 场景: 仅导出已选资源 - JSON

- **假设** 本测试独立创建两条资源，网关中另有未选择资源
- **当** 进入批量操作，勾选这两条资源，导出已选资源并选择JSON格式
- **那么** 必须成功下载，operationId集合恰好是所选两条，不能包含未选资源

## 场景: 仅导出已选资源 - YAML

- **假设** 本测试独立创建两条资源，网关中另有未选择资源
- **当** 进入批量操作，勾选这两条资源，导出已选资源并选择YAML格式
- **那么** 必须成功下载，operationId集合恰好是所选两条，不能包含未选资源
