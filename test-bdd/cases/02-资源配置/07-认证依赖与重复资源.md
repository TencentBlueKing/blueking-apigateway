# 功能: 资源配置 - 认证依赖与重复资源

**模块**: 资源配置
**页面**: /:id/resource/edit/:resourceId
**优先级**: P1
**前置条件**: 用户已登录；写操作仅使用本次测试网关，动态共享详情仅只读

## 场景: 关闭用户认证清除个人令牌并持久化

- **当** 开启个人令牌后关闭用户认证，再保存
- **那么** 个人令牌变为禁用且关闭，回查用户认证与个人令牌均为false
- **并且** 不出现未捕获异常及非预期失败响应

## 场景: 关闭应用认证清除应用权限并禁止申请

- **当** 开启检验应用权限，再关闭应用认证并保存
- **那么** 应用权限与允许申请权限禁用，回查应用认证、资源权限、允许申请均为false
- **并且** 不出现未捕获异常及非预期失败响应

## 场景: 重复名称和重复方法路径均拒绝且不覆盖原资源

- **当** 分别以相同名称不同路径、不同名称相同方法路径创建资源
- **那么** 均返回400与INVALID_ARGUMENT，原资源名称路径描述未被修改
- **并且** 不出现未捕获异常及非预期失败响应
