**模块**: 31-1.25回归

**需求**: https://iwiki.woa.com/p/4040193667 第 7 版

**前置条件**: 本轮测试网关有已发布资源；只修改自己创建的 MCP Server。

## 场景: 两种认证开关的四种组合保存后指引配置与市场图标一致

- 假设创建了独立 MCP Server，分类有效、工具已发布
- 当依次保存 OAuth2公开客户端/个人令牌的 开开、关开、开关、关关 四种组合
- 那么每次修改成功，重新加载后两个开关的持久化值与操作一致
- 并且使用指引仅为已开启模式显示对应章节，个人令牌章节给出 Bearer 请求头
- 并且启用公开客户端时，四种客户端的配置 JSON 不要求 X-Bkapi-Authorization
- 并且市场中该服务的个人令牌图标与个人令牌开关一致
- 并且测试结束停用并删除独立 MCP Server
