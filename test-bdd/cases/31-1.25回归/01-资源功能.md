# 功能: 1.25 资源功能回归

**模块**: 31-1.25回归
**页面**: /:gatewayId/resource/setting
**需求**: https://iwiki.woa.com/p/4040193667 第 7 版；路由规则 https://iwiki.woa.com/p/4018775301

**前置条件**: 已登录，仅操作本轮创建的测试网关与资源。每个场景创建并清理独立资源。

## 场景: 等价参数路由按方法检测并在修改删除后更新

- 假设同一网关有 GET /prefix/{first}/ 与 GET /prefix/{second}/，另有 POST /prefix/{third}/
- 那么检测结果包含两条 GET 资源，不包含 POST 资源，页面展示冲突
- 当把第二条 GET 改为不同路径
- 那么该组冲突消失
- 当恢复等价路径并删除第一条 GET
- 那么该组冲突再次消失

## 场景: 未配置请求参数不会默认声明无参数

- 假设新资源没有请求参数 schema
- 当展开请求参数
- 那么“该资源无请求参数”未勾选
- 当只修改描述并保存后重新打开
- 那么该复选框仍未勾选

## 场景: Header和Query参数保存后重开保留默认值与说明

- 当在请求参数编辑器添加 Header X-BDD125 和 Query page
- 并且填写各自的默认值与说明并提交
- 那么保存的 schema 包含正确位置、名称、类型、默认值和说明
- 当重新打开编辑页并切换参数标签
- 那么两类参数的默认值与说明均保留

## 场景: JSON生成嵌套Body保存后重开保留结构

- 假设资源请求方法为 POST
- 当在“通过 JSON 生成”编辑器填入 fixtures/1.25/request-body.json 内容并提交
- 那么保存的 Body 包含 profile 对象、items 数组和 count 数值
- 当重新打开编辑页并展开 Body
- 那么仍显示 profile、items、count 字段及正确类型

## 场景: 批量编辑后无需刷新即可生成版本

- 假设已有资源版本覆盖当前全部资源，生成版本按钮置灰
- 当批量编辑独立资源，将公开改为不公开并确认
- 那么修改请求成功，资源 is_public=false，后端 need_new_version=true
- 当退出批量编辑
- 那么无需刷新页面，“生成版本”按钮启用

## 场景: 省略可选WebSocket字段仍可更新资源认证

- 假设标准资源未开启 WebSocket，其余基础字段不变
- 当更新认证配置为校验应用权限，请求不携带可选 enable_websocket 字段
- 那么更新成功且认证配置持久化，不应返回服务器错误
- 说明：这是后端 Web API 合约回归；正常编辑页面会显式传入该字段，不能据此声称页面编辑不可用
