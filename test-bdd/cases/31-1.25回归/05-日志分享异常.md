# 功能: 1.25 日志分享异常处理

**模块**: 31-1.25回归
**页面**: /:gatewayId/access-log/:requestId/
**需求**: https://iwiki.woa.com/p/4040193667 第 7 版，日志分享独立页面

## 场景: 分享的日志不存在时展示明确空结果

- 假设登录用户为本轮测试网关生成一个不存在请求 ID 的有效分享链接
- 当打开分享链接，后端返回成功响应且 results 为空
- 那么页面明确提示未找到日志或暂无数据
- 并且不显示 Invalid Date，不把空结果渲染为有记录的详情
- 说明：本场景只验证日志不存在这一异常路径，不声称日志采集丢失或跨用户权限已验证
