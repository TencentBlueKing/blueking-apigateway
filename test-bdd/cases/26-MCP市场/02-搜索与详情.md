# 功能: MCP市场 - 搜索与详情

**模块**: MCP市场
**页面**: /mcp-market
**优先级**: P1
**前置条件**: 用户已登录；写操作仅使用本次测试创建的网关

## 场景: 搜索不存在的MCP并清空条件

- **假设** 用户已进入目标页面并准备好隔离测试数据
- **当** 输入本次唯一的不存在名称，再清空
- **那么** 搜索请求返回空数组且UI显示搜索结果为空，清空发起无keyword的新请求
- **并且** 页面不存在未捕获异常或非预期失败请求

## 场景: 已公开MCP详情与刷新

- **假设** 用户已进入目标页面并准备好隔离测试数据
- **当** 读取已公开MCP并访问其详情，然后刷新
- **那么** 详情显示对应名称与Tools；没有公开MCP时明确跳过而非通过
- **并且** 页面不存在未捕获异常或非预期失败请求
