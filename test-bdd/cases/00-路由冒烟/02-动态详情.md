# 功能: 全站路由冒烟 - 动态详情

**模块**: 路由冒烟
**页面**: /:id/mcp/detail/:serverId, /components/version, /components/system/:system/detail
**优先级**: P1
**前置条件**: 用户已登录；写操作仅使用本次测试网关，动态共享详情仅只读

## 场景: MCP管理详情深链接

- **当** 为测试网关创建MCP并打开详情
- **那么** 显示对应名称与Tools，测试完成后删除该MCP
- **并且** 不出现未捕获异常及非预期失败响应

## 场景: 组件同步版本深链接

- **当** 使用现有同步历史ID访问版本详情
- **那么** 显示同步版本信息与表格，无历史时明确跳过
- **并且** 不出现未捕获异常及非预期失败响应

## 场景: 系统实时概况深链接

- **当** 使用现有运行系统名称访问详情
- **那么** 显示该系统名称及请求、响应或耗时信息，无数据时明确跳过
- **并且** 不出现未捕获异常及非预期失败响应
