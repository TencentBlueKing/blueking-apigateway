# 功能: 个人工作台 - 标签与空结果筛选

**模块**: 个人工作台
**页面**: /personal-workbench/:tab
**优先级**: P1
**前置条件**: 用户已登录，不审批、撤销或删除共享申请

## 场景: my-apply - API 网关筛选无结果

- **假设** 用户进入my-apply页面
- **当** 切换到API 网关标签并搜索唯一的不存在应用ID
- **那么** 对应标签请求返回200、count=0、results=[]，界面显示搜索结果为空
- **当** 清空应用ID并重新搜索
- **那么** 发起无应用ID条件的新请求，返回有效列表结构
