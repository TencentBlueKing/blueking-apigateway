# 功能: AI网关 - 模型服务界面与异常

**模块**: AI网关
**页面**: /:id/model-services
**优先级**: P1
**前置条件**: 用户已登录；写操作仅使用本次测试创建的网关

## 场景: 模型服务深链接和空列表

- **假设** 用户已进入目标页面并准备好隔离测试数据
- **当** 直接进入新建AI网关的模型服务页面并刷新
- **那么** 模型服务搜索控件存在，列表显示暂无数据
- **并且** 页面不存在未捕获异常或非预期失败请求

## 场景: 未完成配置和未连接时禁止保存

- **假设** 用户已进入目标页面并准备好隔离测试数据
- **当** 打开新建表单，填写名称和Endpoint，再填写非法名称
- **那么** 未通过连接测试时保存禁用，非法名称显示校验提示
- **并且** 页面不存在未捕获异常或非预期失败请求

## 场景: 连通测试失败展示原因并禁止保存

- **假设** 用户已进入目标页面并准备好隔离测试数据
- **当** 配置不可解析的 .invalid 模型地址并执行连通测试
- **那么** 返回明确400错误，界面展示失败原因，保存禁用且服务未持久化
- **并且** 页面不存在未捕获异常或非预期失败请求

## 场景: 超时和Provider异常返回明确校验错误

- **假设** 用户已进入目标页面并准备好隔离测试数据
- **当** 分别提交非法Provider、0秒和301秒超时的模型配置
- **那么** 均返回400与INVALID_ARGUMENT，包含对应字段错误
- **并且** 页面不存在未捕获异常或非预期失败请求
