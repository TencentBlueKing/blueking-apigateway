# 功能: AI 网关 - 模型服务全链路

**模块**: AI网关
**页面**: /gateways/:id/backends
**优先级**: P1
**前置条件**: 用户已登录蓝鲸API网关管理端，拥有可用的模型服务凭证（DeepSeek）

## 场景: 创建AI网关

- **假设** 用户已登录并进入我的网关页面
- **当** 用户通过API创建网关，网关类型选择AI网关（kind=2）
- **并且** 输入网关名称、维护人员，选择不公开
- **那么** AI网关创建成功，返回网关ID
- **并且** 网关列表中可查询到该网关，kind为ai

## 场景: 创建模型服务（DeepSeek）

- **假设** 已存在AI网关，且网关下已有默认环境（prod）
- **当** 用户通过API创建模型服务，kind为ai，provider为deepseek
- **并且** 配置api_key、timeout、model_options
- **并且** 为所有环境提交配置
- **那么** 模型服务创建成功，返回后端服务ID
- **并且** 模型服务列表中可查询到该服务，kind为ai

## 场景: 创建模型服务（OpenAI Compatible）

- **假设** 已存在AI网关
- **当** 用户通过API创建模型服务，provider为openai-compatible
- **并且** 配置endpoint、auth_header、timeout
- **那么** 模型服务创建成功

## 场景: 查询模型服务列表与详情

- **假设** 已存在模型服务
- **当** 用户查询模型服务列表
- **那么** 列表中展示已创建的模型服务
- **当** 用户查询模型服务详情
- **那么** 详情中返回provider、endpoint、masked api_key、timeout等字段
- **并且** api_key经过脱敏处理，不返回明文

## 场景: 编辑模型服务

- **假设** 已存在模型服务
- **当** 用户修改模型服务描述并提交
- **那么** 页面提示保存成功
- **当** 用户修改timeout并提交非掩码api_key
- **那么** 保存成功，detail中timeout已更新

## 场景: 模型服务连接测试

- **假设** 已存在DeepSeek模型服务
- **当** 用户调用连接测试接口
- **那么** 接口返回模型列表或连通性结果

## 场景: 删除模型服务

- **假设** 已存在未关联资源的模型服务
- **当** 用户删除该模型服务
- **那么** 删除成功，列表中不再展示该服务

## 场景: 普通网关不支持模型服务

- **假设** 已存在普通网关（kind=0）
- **当** 用户尝试在普通网关下创建kind=ai的模型服务
- **那么** 接口返回校验错误，提示普通网关不支持模型服务

## 场景: 模型服务provider与必填字段校验

- **假设** 已存在AI网关
- **当** 用户使用不合法的provider创建模型服务
- **那么** 接口返回校验错误
- **当** 用户使用deepseek但未提供api_key
- **那么** 接口返回校验错误，提示api_key必填
- **当** 用户使用openai-compatible但未提供endpoint
- **那么** 接口返回校验错误，提示endpoint必填

## 场景: 模型服务timeout范围校验

- **假设** 已存在AI网关
- **当** 用户提交timeout为0
- **那么** 接口返回校验错误
- **当** 用户提交timeout为301
- **那么** 接口返回校验错误

## 场景: 模型服务kind不可变

- **假设** 已存在模型服务
- **当** 用户尝试更新模型服务时修改kind为standard
- **那么** 接口返回校验错误，提示类型创建后不能修改

## 场景: 创建模型代理API

- **假设** 已存在AI网关和模型服务
- **当** 用户通过API创建资源，kind为ai，method为POST
- **并且** 关联模型服务后端，backend.config为空对象
- **那么** 模型代理API创建成功，返回资源ID

## 场景: 查询与编辑模型代理API

- **假设** 已存在模型代理API
- **当** 用户查询资源列表
- **那么** 列表中展示该资源，kind为ai
- **当** 用户修改资源描述并提交
- **那么** 保存成功

## 场景: 删除模型代理API

- **假设** 已存在模型代理API
- **当** 用户删除该资源
- **那么** 删除成功，列表中不再展示

## 场景: 模型代理API仅支持POST

- **假设** 已存在AI网关和模型服务
- **当** 用户创建kind=ai的资源但method为GET
- **那么** 接口返回校验错误，提示仅支持POST

## 场景: 模型代理API后端类型匹配校验

- **假设** 已存在AI网关，同时存在普通后端和模型服务
- **当** 用户创建kind=ai的资源但关联普通后端（kind=standard）
- **那么** 接口返回校验错误，提示资源类型与后端服务类型不匹配

## 场景: 资源kind不可变

- **假设** 已存在模型代理API
- **当** 用户尝试更新资源时修改kind为standard
- **那么** 接口返回校验错误，提示类型创建后不能修改

## 场景: 生成资源版本

- **假设** 已创建模型代理API
- **当** 用户生成资源版本
- **那么** 版本生成成功，版本列表中可查询到新版本

## 场景: 发布模型代理API到环境

- **假设** 已生成资源版本
- **当** 用户将版本发布到prod环境
- **那么** 发布成功，发布记录中可查询到发布历史
- **并且** 环境资源信息中可查询到已发布的模型代理API

## 场景: AI网关全链路清理

- **假设** AI网关全链路测试已完成
- **当** 用户停用并删除AI网关
- **那么** AI网关删除成功，列表中不再展示
