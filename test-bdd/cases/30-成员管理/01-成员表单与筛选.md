# 功能: 成员管理 - 表单与筛选

**模块**: 成员管理
**页面**: /:id/members
**优先级**: P1
**前置条件**: 用户已登录；写操作仅使用本次测试创建的网关

## 场景: 新增成员必须选择用户

- **假设** 用户已进入目标页面并准备好隔离测试数据
- **当** 未选择用户时提交新增成员表单
- **那么** 提示请选择人员，表单仍保留；取消后原管理员仍在列表中
- **并且** 页面不存在未捕获异常或非预期失败请求

## 场景: 查看角色权限并取消变更

- **假设** 用户已进入目标页面并准备好隔离测试数据
- **当** 打开管理员角色变更，查看权限矩阵后取消
- **那么** 管理员与运营者权限可见，取消后管理员角色不变
- **并且** 页面不存在未捕获异常或非预期失败请求

## 场景: 搜索不存在的成员并恢复

- **假设** 用户已进入目标页面并准备好隔离测试数据
- **当** 搜索不存在的用户名，再清空搜索
- **那么** 空结果时没有管理员行，清空后恢复管理员行
- **并且** 页面不存在未捕获异常或非预期失败请求
